# Automated Banking Transaction Analysis & Visualization Dashboard

## Project Overview
This project focuses on analyzing banking transaction data and presenting key insights through an interactive Power BI dashboard. The dashboard helps understand transaction patterns, customer activity, transaction distribution across locations, and customer gender-based transaction analysis.

## Objectives
- Analyze overall banking transaction amounts.
- Identify transaction patterns across different locations.
- Understand transaction distribution by customer gender.
- Analyze transaction trends over time.
- Identify customers with the highest transaction amounts.
- Provide interactive filtering using date and gender slicers.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning and Data Transformation

## Dataset Description
The dataset contains banking transaction and customer information.

### Columns Used
- TransactionID
- CustomerID
- CustomerDOB
- CustGender
- CustLocation
- CustAccountBalance
- TransactionDate
- TransactionTime
- TransactionAmount (INR)

## Dashboard KPIs
- Total Transaction Amount
- Average Transaction Amount
- Unique Customers
- Average Account Balance

## Dashboard Visualizations
1. **Top 10 Transaction Locations** – Compares transaction amounts across the top transaction locations.
2. **Transaction Amount by Gender** – Displays the distribution of transaction amounts by gender.
3. **Transaction Trend Over Time** – Visualizes daily transaction amount trends.
4. **Transaction Amount by Customer** – Highlights the top 5 customers based on transaction amount.
5. **Highest Transaction Location** – Displays the location with the highest transaction amount.

## Interactive Filters
- Transaction Date slicer
- Customer Gender slicer

These slicers allow users to interact with the dashboard and analyze data for selected date ranges and gender categories.

## Key Insights
- The dashboard displays a total transaction amount of approximately **400.60K INR**.
- The average transaction amount is approximately **2.00K INR**.
- The dashboard identifies **200 unique customers**.
- The average account balance is approximately **65K INR**.
- Kolkata is displayed as the highest transaction location in the current dashboard view.
